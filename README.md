# BSc-Project-Molecular-Docking-ML
Molecular Docking and Machine Learning Analysis of Ligands Against InhA Target Protein of Mycobacterium tuberculosis

## About the Project
This project focuses on molecular docking and machine learning analysis
of ligands against the InhA target protein of Mycobacterium tuberculosis.

## Objectives
- Identify potential ligands against InhA
- Perform molecular docking
- Analyze binding affinity
- Apply machine learning to predict binding affinity

## Tools & Technologies
- Python
- RDKit
- PyMOL
- PRANKWeb
- PyRx / AutoDock Vina
- Machine Learning
- Linear Regression

## Dataset
20 ligands were analyzed using molecular descriptors and docking results.

## Machine Learning
Features:
- Molecular Weight
- H-bond Acceptors
- H-bond Donors
- Lipinski Violations
- XlogP
- TPSA

Target:
- Binding Affinity (kcal/mol)

## Results
The docking results and machine learning results are provided
in the Results folder.
